# replace_text.py

Утилита для замены текста в файлах с безопасным режимом предпросмотра.

[К оглавлению](../README.md)

Работает на **Python 3.11+**. Внешних зависимостей нет.

## Возможности

- **Безопасный dry-run по умолчанию** — без флага `--apply` ничего не записывается, только показывается план изменений.
- **Гибкий выбор файлов** — glob-шаблоны (`*.conf`, `*.txt`, `*`) и рекурсивный обход подпапок (`-r`).
- **Поддержка кодировок** — UTF-8, UTF-8-BOM, CP1251, UTF-16. Файл записывается в исходной кодировке с сохранением BOM.
- **Пропуск бинарных файлов** — определяется по нулевым байтам и неудачному декодированию.
- **Режим `--first`** — заменять только первое вхождение в каждом файле (по умолчанию — все вхождения).
- **Подробный отчёт** — список файлов, количество совпадений, строка до/после.
- **Защита от случайной записи** — запрос подтверждения перед применением (отключается флагом `-y`).

## Быстрый старт

### 1. Посмотреть, что будет изменено (dry-run)

```powershell
python replace_text.py --find "OLD_TEXT" --replace "NEW_TEXT"
```

По умолчанию ищет в `*.conf` в текущей папке без рекурсии.

### 2. Применить изменения

```powershell
python replace_text.py --find "OLD_TEXT" --replace "NEW_TEXT" --apply
```

Будет запрошено подтверждение. Для запуска без вопросов (например, из скрипта) добавьте `-y`.

## Использование

```
python replace_text.py --find ТЕКСТ --replace ТЕКСТ [опции]
```

### Аргументы

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--find` | *(обязательный)* | Текст, который нужно найти |
| `--replace` | *(обязательный)* | Текст для замены |
| `--path` | `.` | Папка для поиска |
| `--pattern` | `*.conf` | Glob-шаблон: `*.conf`, `*.txt`, `*` |
| `-r`, `--recursive` | выкл. | Обход подпапок |
| `--first` | выкл. | Заменять только первое вхождение в каждом файле |
| `--apply` | выкл. | Реально записать изменения (иначе — dry-run) |
| `-y`, `--yes` | выкл. | Не спрашивать подтверждение при `--apply` |
| `--max-preview` | `10` | Сколько файлов показывать в предпросмотре |
| `-h`, `--help` | — | Справка |

В PowerShell шаблон передавайте в кавычках, иначе оболочка раскроет `*` сама:

```powershell
python replace_text.py --find "old" --replace "new" --pattern "*.txt"
```

## Примеры

### Все `.conf`, все вхождения, текущая папка

```powershell
# посмотреть план
python replace_text.py --find "old_host" --replace "new_host"

# применить
python replace_text.py --find "old_host" --replace "new_host" --apply
```

### Все `.conf` рекурсивно, только первое вхождение в каждом файле

```powershell
python replace_text.py --find "old" --replace "new" --pattern "*.conf" -r --first --apply
```

### Все `.txt` рекурсивно

```powershell
python replace_text.py --find "foo" --replace "bar" --pattern "*.txt" -r --apply
```

### Все читаемые файлы в папке

```powershell
python replace_text.py --find "foo" --replace "bar" --pattern "*" -r
```

Бинарные и нечитаемые файлы будут автоматически пропущены (попадут в счётчик `Пропущено`).

### Работа с другой папкой

```powershell
python replace_text.py --path "C:\Users\User\configs" --find "old" --replace "new" --pattern "*.conf" -r
```

### Автоматический запуск без подтверждения

```powershell
python replace_text.py --find "old" --replace "new" --apply -y
```

## Безопасный workflow

Рекомендуется всегда работать в два шага:

```powershell
# 1. Посмотреть план — убедиться, что заменяется именно то, что нужно
python replace_text.py --find "OLD" --replace "NEW" --pattern "*.conf" -r

# 2. Применить, подтвердив вводом "y"
python replace_text.py --find "OLD" --replace "NEW" --pattern "*.conf" -r --apply
```

## Поведение и ограничения

### Кодировки

Скрипт читает файл в такой последовательности:

1. **UTF-16** — если начинается с BOM `FF FE` / `FE FF`
2. **UTF-8** — с сохранением или снятием BOM `EF BB BF`
3. **CP1251** — как запасной вариант для Windows-файлов

При записи файл сохраняется в той же кодировке и с тем же BOM, что были при чтении:

- UTF-8 файл остаётся UTF-8
- UTF-8-BOM файл остаётся с BOM
- CP1251 файл остаётся в CP1251

### Бинарные файлы

Файл считается бинарным и пропускается, если:

- содержит нулевой байт `\x00` (кроме UTF-16, где это норма), или
- не удаётся декодировать ни в UTF-8, ни в CP1251.

### Переводы строк

Скрипт не меняет переводы строк (`\r\n` и `\n`): читает как есть и пишет как есть.

### Символы, требующие экранирования

В PowerShell при передаче `--find` / `--replace` со спецсимволами (`$`, `` ` ``, `"`) используйте одинарные кавычки:

```powershell
python replace_text.py --find '$VAR' --replace '$NEW_VAR'
```

## Возможные проблемы

### `ОШИБКА: путь не найден или не папка`

Проверьте параметр `--path`: он должен указывать на существующую папку.

### Файл пропущен, хотя в нём точно есть текст

Вероятные причины:

- файл в кодировке, отличной от UTF-8 / CP1251 / UTF-16 (например, KOI8-R);
- файл содержит нулевые байты;
- файл не имеет прав на чтение.

### Замена не произошла из-за прав

Запустите PowerShell от имени администратора либо снимите атрибут «только чтение» с файлов.
